What it does

Full admin layout: sidebar, top bar, 4 KPI cards, revenue trend, plan-mix donut, channel bars and a customer table
Hand-drawn SVG charts, no chart library: area chart with previous-period line, donut, bars and sparklines
Range switch (7D / 30D / 90D / 12M) morphs every chart in a wave, with a scanning light beam and rolling numbers
Hover or arrow-key through the revenue chart for a tooltip with the change vs the previous period
Light and dark themes, searchable and sortable table, springy range indicator
Responsive down to 390px: icon rail on tablets, slide-out drawer on phones, zero dependencies

Use it in 2 minutes

  1. Unzip and copy the CSS and JS into your project.
  2. Paste the markup where you want it.
  3. Change the CSS variables to match your brand.
<link rel="stylesheet" href="meridian.css">
<div class="meridian" data-meridian>
  <!-- sidebar, KPI cards and charts from index.html -->
</div>
<script src="meridian.js"></script>
<script>
  const dash = Meridian.mount(document.querySelector('[data-meridian]'), {
    range: '30d',
    data: myRevenueData   // same shape as Meridian.data
  });
  dash.setRange('90d');
</script>
