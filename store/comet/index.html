What it does

Keeps looping until your request finishes, then celebrates with a burst and a check
Hook it to fetch(), FormData or any promise with one option

Use it in 2 minutes

  1. Unzip and copy the CSS and JS into your project.
  2. Paste the markup where you want it.
  3. Change the CSS variables to match your brand.
<link rel="stylesheet" href="comet.css">
<button class="comet" data-comet
        data-label="Submit" data-done="Sent"></button>
<script src="comet.js"></script>
<script>
  Comet.mount(document.querySelector('[data-comet]'), {
    send: () => fetch('/api/contact', { method: 'POST', body: new FormData(form) })
  });
</script>
