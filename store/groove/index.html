What it does

Full admin layout: sidebar with a payout card, top bar with a release switch and Play release button, 4 KPI cards with sparklines, the turntable with tracklist, platform donut with age bars, 30-day streams chart, listening heatmap, top-cities table and playlist adds
Hand-drawn turntable (no library): plinth, platter, vinyl with real grooves, a spinning label in the release's colours and a tonearm that swings on, tracks the record from the outer groove to the run-out and lifts back to its rest
Every track is a groove sized by its running time; as the needle reaches it the groove lights up, a glowing ring sized by its share of streams unspools from the needle, sound waves pulse and its streams, running time and play count roll up
Charts re-draw in a wave on every switch: daily streams vs the previous release with a release-day marker, a 7x24 listening heatmap with hourly totals, a morphing platform donut, age bars, rolling KPIs
Hover or tab through grooves for track length, streams and save rate; click a track to spotlight its groove; crosshair tooltips on the streams chart
Light and dark themes, responsive down to 390px (icon rail on tablets, slide-out drawer on phones), reduced-motion support, zero dependencies

Use it in 2 minutes

  1. Unzip and copy the CSS and JS into your project.
  2. Paste the markup where you want it.
  3. Change the CSS variables to match your brand.
<link rel="stylesheet" href="groove.css">
<div class="groove" data-groove data-groove-manual>
  <!-- sidebar, KPI cards, turntable and charts from index.html -->
</div>
<script src="groove.js"></script>
<script>
  const deck = Groove.mount(document.querySelector('[data-groove]'), {
    data: myReleases   // same shape as Groove.data
  });
  deck.setRelease(1);  // the needle reads the second release
</script>

Questions

Can I plug in my own streaming data?

Yes. Pass Groove.mount() a data array with one entry per release: name, kind, release date, label colours, tracks ([name, 'm:ss', streams, saveRate]), listeners, saves, KPI deltas, platform and age shares, cities and playlist adds; daily streams can be passed as days[30] or generated from a curve. Feed it from your distributor's CSV export, an analytics API or any JSON and call setRelease() or play() to spin it again.
